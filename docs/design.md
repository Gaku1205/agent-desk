# agent-desk デザイン仕様

画面の見た目のルール。2026年11月15日に、それまでの「流れ × 誌面」（光の粒・極太の数字・画面全体の川）をやめ、**1カラムの会話形式**に作り直した（Issue #281。画面案は作らず、この文章で決めた）。挙動のルールは `docs/spec.md`。

## 方針

- 体験の核：**開くと、画面の真ん中に「今あなたが答えること」が1つだけある。** 質問・説明とボタン（と答えの欄）だけが最初の1画面に見え、片づけると次の1件に替わる。その下に、AIたちの進み具合が、会話のメッセージのように縦に流れる
- 画面は**読みやすい幅の1本の列**（PC では中央の細めの1列）。左右に別の列を置かない。画面の比率が変わっても、列の幅と並びは変わらない
- **余白と文字が中心**。色は最小（地・文字・薄い文字・強調の1色（アンバー）と失敗の赤）。大きさ・太さ・行間・余白の差で、何が主役かを見せる。地味で無難な画面にしない（行間を詰めた小さい字の羅列、どこも同じ大きさの字にしない）
- 雰囲気の参考は Claude アプリの会話画面（コピーはしない）：少し温かい地に、生成りの文字、広い行間
- **軽く**：光の粒・極太の数字・キャンバスの描画・すりガラス（`backdrop-filter`）・凝った動きは使わない。動きは切り替わりの短いフェードだけ
- **避けること**：数字を大きく並べたタイル、同じ角丸・同じ影のカードの並び、ピル型バッジの多用、飾りのグラデーション、絵文字、太い枠・硬い黒線、見出し上の字間を空けた英大文字、光る点・にじみ、標準のフォーム部品をそのまま枠に並べた物、塗りつぶしのアンバーを「オン」などの状態に流用すること
- 状態は色だけで伝えない。「あなたの番」は種類の札と説明文、会話は話し手と文を持つ
- **強い色は、ほんとうに急ぐ所だけ**：アンバーの塗り（ボタン）は「止まった」の1件だけ、赤の塗りは「公開失敗」の1件だけ。ほかの1件の主役のボタンは生成り（`--bone`）の塗り
- **キーボード**：Tab で回る数を少なく保つ。最初に届くのは「あなたの番」の1件のボタン
- リンク：アプリの中のページ（`/` で始まるURL）は同じタブで開く。外のサイト（`https://`）だけ新しいタブで開く
- 文言は人の言葉で短く。会話の文は「いま〇〇が△△しています」のように、声に出して読める日本語にする。日本語の文は「、」「。」で分けた塊ごとに折る（文節の途中で切らない）

## 色

CSSカスタムプロパティとして `globals.css` の `:root` に定義し、コードではこの名前で使う。

| --- | --- | --- |

| `--bone` | `#ECE8DF` | 文字（見出し・題名・会話の文） |
| `--bone-2` | `#A9A59C` | 説明文・会話の題名 |

ダークのみ。ライトテーマは作らない。

## 文字

- 和文：`IBM Plex Sans JP`（400 / 500 / 700）。欧文・数字：`Geist`（可変）。ワードマーク：`Bricolage Grotesque` 800（`font-variation-settings: "opsz" 96`）
- 3つとも `next/font/google` で読む（`src/app/layout.tsx`。変数は `--font-jp`・`--font-latin`・`--font-disp`）。本文の指定は `--jp`（Geist → IBM Plex Sans JP の順）
- 等幅フォントは使わない。番号・時刻・件数は Geist の `tabular-nums`（`.num`）で桁をそろえる
- 大きさの段（PC／スマホ）：
  - 「あなたの番」の題名 30px／21px（700、行の高さ1.4、字間 −0.01em、`text-wrap: balance`）
  - 「あなたの番」の説明文 17.5px／15.5px（行の高さ1.8）
  - 会話の文 16px／15.5px（行の高さ1.75）
  - 小見出し・札・ボタン 13〜14.5px、補足 12.5〜13px
- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 文字の色は、地に対して 4.5:1 以上になる物だけを使う（`--bone`・`--bone-2`・`--mute`・各 `-soft`。不透明度を下げて薄くした文字は作らない）
- 本文は `font-feature-settings: "palt"`（かなを詰める）
- **改行**：`word-break: auto-phrase`（文節の途中で切らない）。説明文は「、」「。」のあとで `span.ph` に分け、塊ごとに折る（`src/lib/turnKind.ts` の `splitPhrases`）。折り返さない物（`white-space: nowrap`）：番号、時刻・待ち時間、ボタンの文字、足あとの1つ1つ

## 寸法（共通）

| 名前 | 値 |
| --- | --- |
| `--gutter`（左右の余白） | `clamp(20px, 2.2vw, 40px)`。スマホ 16px |
| `--top-h`（上端の帯） | 52px |
| `--col`（列の幅） | 680px（PC）。列は `width: min(var(--col), 100% − 2×--gutter)`、左右中央 |
| 角丸 | 札・ボタン 8px、「あなたの番」の面 14px。それ以上丸くしない |
| 影 | 使わない。光（にじみ）も使わない |
| 動きの曲線 `--ease` | `cubic-bezier(.2,.8,.2,1)` |
| フォーカス | `box-shadow: 0 0 0 2px var(--bg), 0 0 0 3.5px var(--bone)`、角丸4px。どの部品も同じ |

## あなたの番（真ん中の1件）

`src/components/Desk.tsx`（並べ方）と `src/components/TurnRow.tsx`（1件）。並び順の先頭の1件だけを、1つの面に出す（挙動は `docs/spec.md` の「あなたの番」）。

- **見出しの行**（面の外、上。下14px）：左に `あなたの番`（13px / 700・`--you`。`<h1 id="turn-title" tabIndex={-1}>`）、右端に `ほかに 7件`（13px・`--mute`、数は `--bone-2` 500。残りが0なら出さない）
- **面**：地 `--raise`、縁 `inset 0 0 0 1px var(--hair)`、角丸14px、内側 上32px・左右36px・下32px（スマホ 22px・18px・22px）。影は付けない。中の段の間は下のとおり
- 1段目（下14px）：**種類の札**（13px / 700。止まった＝`--you`、公開失敗＝`--fail-soft`、ほか（保留・未着手・質問・工場の相談・PR作成待ち・マージ待ち）＝`--bone`）→ `todo-app#23　PR #38`（13px・`--mute`）→ 待ち時間 `46分`（13px・`--mute`）→ 右端に今の段階の名前（`修正`。13px・`--mute`）。間12px。入らなければ折り返す
  - 種類の札の文言（`src/lib/turnKind.ts`）：止まった／保留／未着手／質問／工場の相談／PR作成待ち／マージ待ち／公開失敗
- 2段目：題名（30px / 700・`--bone`、行の高さ1.4、字間 −0.01em、`text-wrap: balance`。スマホ 21px）。GitHub の Issue へのリンク（乗せたら下線 1px・`text-underline-offset: 4px`）
- 3段目（上14px）：説明文（17.5px・`--bone-2`、行の高さ1.8。スマホ 15.5px。文言は下の「段階ごとの説明文」）。公開失敗の理由（`note`）はその下（上6px）に 14px・`--fail-soft`
- 答える欄（質問・工場の相談だけ。上22px。下の「質問に答える欄」「工場の相談に答える欄」）
- 4段目（上24px）：ボタンの並び（間8px、入らなければ折り返す）。最後は `ログを開く ↗` などの文字のリンクでもよい
- **ボタン**（`.act`）：高さ42px、左右20px、角丸8px、14.5px / 500。幅は文字で決まる（固定しない）。スマホは高さ44px・15px
  - **主役のボタン**（並びの最初の1つ）：止まった（`再開`）＝地 `--you`・文字 `#1A1206`、乗せたら `#FFB95A`。公開失敗（`確認する`）＝地 `--fail`・文字 `#1A0808`、乗せたら `#FF7676`。ほか＝地 `--bone`・文字 `--bg`、乗せたら `#F6F2E9`
  - **ほかのボタン**（2つ目から）：地なし、縁 `inset 0 0 0 1px rgba(236,232,223,.18)`、文字 `--bone`。乗せたら地 `--well`
  - **押した瞬間**（`:active` と、押してから220ms）：主役は不透明度 .85、ほかは地 `--well`。色は `transition` を付けず即座に変える（100ms以内に反応が見える）。操作の最中（`aria-disabled`）は不透明度0.55（押した直後の220msは1）
  - `答えを送る` は、選ぶか書くまでは `aria-disabled="true"`：不透明度0.55
  - `ログを開く ↗`（止まった理由にこのリポジトリのログのURLがあるときだけ）は文字だけ（14px・`--bone-2`、乗せたら `--bone`、高さ42px、左右8px）
  - `確認する`（公開失敗）はボタンと同じ見た目のリンク（PRへ、新しいタブ。デモなどアプリの中のページへ向くときは同じタブ）
- **マージの確認**：`マージ…` を押すと、その場でボタンの並びが `マージする` と `やめる`（ほかのボタンと同じ縁だけ・文字 `--bone-2`）に変わり、説明文の所に結果を3行出す（`src/lib/mergeLines.ts`）。ボタンの形は **レビューが指摘なしかどうか**で変える：
  - 指摘なし：`マージする` は主役のボタン（地 `--bone`・文字 `--bg`）
  - 未実施・指摘あり：`マージする` を弱める（地なし、縁 `inset 0 0 0 1px rgba(255,138,141,.32)`・文字 `--fail-dim`、乗せたら地 `rgba(242,92,92,.1)`）。押せるが、塗りつぶしの主役にはしない
  - 3行は **空白でそろえず、CSS grid の3列**（`ul` を `grid-template-columns: max-content max-content minmax(0,1fr)`、各 `li` は `subgrid`。列の間 `0 12px`、行の高さ1.8）：印（`✓` `×` `–` `→`。14px）／名前（`check` `review` `deploy`。14px・`--mute`）／結果（14px）。`✓ check 4/4 通過`／`✓ review 指摘なし`（指摘ありは `× review 指摘あり`、未実施は `– review 未実施`）／`→ deploy マージ後にVercelが公開`。通常の行は印 `--bone-2`・結果 `--bone-2`（`deploy` の行の印は `--mute`）。**レビューが指摘あり・未実施の行は、印と結果を `--fail-dim`**（名前は `--mute` のまま）
  - フォーカスは `マージする`（押し続けた Enter の繰り返しでは押せない）。`Esc` か `やめる` で元に戻る。マージ中は `マージ中…`。ダイアログは開かない

  - 質問の文：13.5px・`--bone`、行の高さ1.55。前に `Q1`（12px・`--mute`、右8px）
  - 選択肢のボタン（`role="radio"`、間6px、入らなければ折り返す）：高さ30px以上・左右12px・角丸5px・12.5px / 500・縁 `inset 0 0 0 1px rgba(236,232,223,.16)`・文字 `--bone`、長い文は折り返す。中は `A`（12px・`--mute`）・文・おすすめの印 `· おすすめ`（11.5px・`--bone-2`）を間7pxで並べる。乗せたら地 `--well`。**選んだ物は `--bone` に塗りつぶし、文字（`A`・おすすめも）は `--bg`**（アンバーは使わない）

  - 画面案：見出し `画面案`（12px・`--mute`）＋ `どちらの画面にしますか`（13.5px・`--bone`）。案は横に並べる（`grid`、1つの幅220px以上で入るだけ、間10px。スマホは1列）。1つの案は押せる枠（`role="radio"`、左右上下10px・角丸6px・縁 `rgba(236,232,223,.16)`、乗せたら地 `--well`）で、上に `A`（Bricolage Grotesque 800・20px・`--bone`）と見出しの文（12.5px・`--bone-2`、入らなければ「…」）、下に PC の画像（高さ180pxまで。縦横の比は崩さず、伸ばさない）とスマホの画像（幅64px・高さ140pxまで）を間8pxで下端にそろえて並べる（画像の地 `#1C1D21`・角丸3px）。**選んだ案は地 `--well`・縁 `inset 0 0 0 1.5px var(--bone)` で、見出しの右端に `選んだ案`（11.5px / 500・`--bone`）**（色だけで伝えない）

## 動き（まとめ）

| 場所 | 動き | 長さ |
| --- | --- | --- |
| 「あなたの番」の1件が替わった | 新しい1件が不透明度0から1へ（動かさない） | 0.18秒 |
| 新しく入った会話のメッセージ・開いた公開済み | 不透明度0から1へ | 0.18秒 |
| ボタンを押した | 色が即座に変わる（100ms以内） | — |
| 同期の点 | 速い更新の間は2秒周期に明滅、取り直し中は0.8秒周期に脈打つ | — |
| 押した札の点・押した `設定` の歯車 | 次の画面が出るまで0.8秒周期に脈打つ（動きを減らすときは色が `--bone` に変わるだけ） | 画面が出るまで |
| スマホのメニュー | 左から0.18秒で滑り込む | 0.18秒 |
| デモの知らせ | 下から10px上がりながら0.2秒で出る | 0.2秒 |
| 設定のランプ | 押している間は縮み（`scale(.7)`）、離すと戻る。光は0.12秒で入れ替わる | 0.22秒 |
| ログイン（スマホ）の段階の一覧 | 1つの光が上から下へ、1段階1秒で通る（8秒でくり返し） | ずっと |

- 曲線は `--ease`（`cubic-bezier(.2,.8,.2,1)`）。動きは CSS の `transition`・`@keyframes` だけで作る（キャンバスは使わない）。アニメーション用のライブラリは入れない
- **動きを減らす**：端末の `prefers-reduced-motion: reduce`（設定が「端末の設定に従う」のとき）と、設定の「アニメーション：オフ」（`<html data-motion="reduce">`）。「オン」（`data-motion="full"`）は端末の設定にかかわらず動かす。判定は CSS（`globals.css`。すべての `animation`・`transition` を止める）と JS（`src/lib/motion.ts` の `isMotionReduced`）で同じ
