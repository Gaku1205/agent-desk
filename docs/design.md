# agent-desk デザイン仕様

画面の見た目のルール。2026年10月29日に、構図の違う下書き3案を比べて決めた方向「流れ × 誌面」（下書き：`docs/mockups/flow-editorial.html`。見本であり、本番のコードではない）を文章にしたもの。挙動のルールは `docs/spec.md`。

## 方針

- 体験の核：**夜の地を左から右へ流れる光の粒の中に、自分の Issue が段階ごとに浮かんでいて、その同じ流れが左下の極太の数字の中も通り抜けている。** ボタンを押すと、その Issue の光が次の段階へ跳ねて流れに戻る
- 画面は上下の2つ。**上は「流れ」**（Issue が光の粒になって、段階の列を左から右へ進む映像）、**下は「誌面」**（巨大な数字 ＋ 押す列 ＋ 出来事）。パネルで区切った定番の画面にしない
- 映像は画面の端まで届かせる。文字の後ろだけすりガラス（`backdrop-filter`）にし、その上の端は `mask-image` のグラデーションで消す（硬い境目を作らない）。板で画面を分けない
- 生きている映像は**1系統だけ**：画面全体の川（背景の粒）。流れの光の粒も、巨大な数字の中の粒も、同じ式で同じ向き・同じ速さに動く。ほかの場所に常に動く物を置かない（毎日見て疲れない量にする）
- 名札・補足は端に置き、短く。大きさの差でアクセントを作る（巨大な数字と小さな「件」）
- **避けること**：数字を大きく並べたタイル、同じ角丸・同じ影のカードの並び、ピル型バッジの多用、飾りのグラデーション、絵文字、太い枠・硬い黒線・全面の縦線、見出し上の字間を空けた英大文字、左上の小さいタイトル＋1行の説明文、標準のフォーム部品をそのまま枠に並べた物
- 状態は色だけで伝えない。流れの名札は短い説明の文字を持ち、押す列は「種類」の札と説明文を持つ
- 文言は人の言葉で短く。名札は1語（英語1語も可）。日本語の文は「、」「。」で分けた塊ごとに折る（文節の途中で切らない）

CSSカスタムプロパティとして `globals.css` の `:root` に定義し、コードではこの名前で使う。映像（canvas）は同じ値を RGB で持つ（`src/components/flow/engine.ts` の `WHO_RGB`）。

| --- | --- | --- |
| `--bg` | `#0B0C10` | 夜（少し青い地） |
| `--bone` | `#ECE8DF` | 文字（見出し・題名） |
| `--bone-2` | `#A9A59C` | 説明文 |
| `--mute` | `#6B6963` | 補足（番号・時刻・名札の薄い字） |
| `--you` | `#F5A73A` | あなたの番（アンバー。巨大な数字の光もこの系統） |
| `--ai` | `#5B8DFF` | AIの番（信号の青） |
| `--q` | `#9B7CF5` | 待機（順番待ち・やり直し待ち。デモの印もこの色） |
| `--fail` | `#F25C5C` | 失敗（CI失敗・公開失敗） |
| `--done` | `#4DD39A` | 公開済み |
| `--you-soft` / `--fail-soft` / `--done-soft` | `#FFC06A` / `#FF8A8D` / `#7BDCAE` | 文字に使うときの明るい版（出来事の足あと、注意の文） |

誰の番かの色：人間＝`--you`、AI＝`--ai`、待機＝`--q`、失敗＝`--fail`、公開済み＝`--done`。段階と誰の番かから色を決める処理は `src/lib/flow/nodes.ts` の `whoOf`（公開済み → done、CI失敗・公開失敗 → fail、順番待ち・やり直し待ち → queue、それ以外は人間の番なら human・でなければ ai）。

ダークのみ。ライトテーマは作らない。

## 文字

- 和文：`IBM Plex Sans JP`（400 / 500 / 700）。欧文・数字：`Geist`（可変）。見出し・巨大な数字・ワードマーク：`Bricolage Grotesque` 800（`font-variation-settings: "opsz" 96`）
- 3つとも `next/font/google` で読む（`src/app/layout.tsx`。変数は `--font-jp`・`--font-latin`・`--font-disp`）。本文の指定は `--jp`（Geist → IBM Plex Sans JP の順）、見出しは `--disp`
- 等幅フォントは使わない。番号・時刻・件数は Geist の `tabular-nums`（`.num`）で桁をそろえる
- 字間：ワードマーク `-0.045em`、巨大な数字 `-0.06em`、「件」 `-0.04em`、題名 `-0.005em`
- 大きさの段：巨大な数字 `--giant`（`clamp(160px, 13vw, 340px)`、スマホ 128px）／「件」30px（スマホ 26px）／題名 16px（スマホ 15.5px）／本文 13.5px・13px／小 12.5px・12px／流れの名札 `--nfs`（`clamp(11.5px, .23vw + 9.2px, 15px)`。幅で変える）／段階の目盛り 12px、その件数 11.5px
- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 本文は `font-feature-settings: "palt"`（かなを詰める）
- **改行**：`word-break: auto-phrase`（文節の途中で切らない）。説明文は「、」「。」のあとで `span.ph` に分け、塊ごとに折る（`src/lib/turnKind.ts` の `splitPhrases`）。折り返さない物（`white-space: nowrap`）：名札、番号、時刻・待ち時間、ボタンの文字、段階名、出来事の足あとの1つ1つ

## 映像（画面全体）

`src/components/flow/engine.ts`。画面いっぱいの2枚の `position: fixed` の canvas（`pointer-events: none`）。

- **霧**（下の層。`z-index: 0`、不透明度0.9）：1/4 の解像度で描いて引き伸ばす。5つの大きな丸い光（位置は画面の割合、色・不透明度：`(.14,.42) 人間 .2`、`(.55,.3) AI .18`、`(.9,.4) 公開済み .13`、`(.36,.7) AI .12`、`(.72,.74) 待機 .1`、半径は画面の長い辺の36%）が、ごくゆっくり漂う（x は `.04·sin(t·.09+…)`、y は `.05·cos(t·.07+…)`）。すりガラスがこれをぼかす。3フレームに1回描く
- **川**（上の層。`z-index: 3`。すりガラス（`z-index: 2`）より上に描く：ぼかしの層の下に粒を置かない）：粒の数は PC `min(900, 幅×高さ÷1800)`、スマホ 220。色 `150,165,205`、大きさ 4px×(0.5〜1.7)、不透明度 0.15 にゆらぎ（`.55+.45·sin(t·1.1+位相)`）。右へ 24px/秒 ＋ ノイズの curl（発散しない流れ。振幅 12）で揺れながら流れ、右端を出たら左端から入り直す。誌面の上端（＋30px）より下では不透明度を 0.3 倍にする
- 粒の初期位置は種から決まる乱数（`src/lib/flow/random.ts`）で、見た目のテストで毎回同じになる
- `devicePixelRatio` は 1.5 まで（川）、2 まで（巨大な数字）
- **動きを減らす**（下の「動き」）：時間を進めず、川・粒・ばねを止める。画面の大きさ・データ・スクロールが変わったときだけ描き直す

## 流れ（PC）

`src/components/flow/FlowStage.tsx`（要素）と `src/lib/flow/layout.ts`（配置の純粋関数）。

- 場所：上端の帯の下、高さ `--flow-h`、左右の余白 `--gutter`。`overflow: hidden`
- **段階の目盛り**（上端、`position: absolute`、上4px）：8列の grid（`repeat(8, minmax(0,1fr))`）に `清書 実装 PR CI レビュー 修正 マージ 公開`（12px・`--bone-2`、列の左端から26px）と、その段階にある Issue の数（11.5px・`--mute`、名前との間6px。0なら出さない）。名前の下に1px×7pxの短い目盛り線（`--mute`・不透明度0.6）
- **光**（canvas）：各 Issue が1つの光。列 `k` の光の x は `列の左端 + 26px`（`DOT_OFFSET`）。名札は光の右18px（`LABEL_GAP`）から。右端に入らない物は光を右端（`幅 − 26px`）に置き、名札を光の左19px（`LABEL_GAP_FLIP`）から左へ出す（`flip`）
  - 光の芯：丸い点。人間 7.5px、ほかは 6px（×大きさの係数 `sc = clamp(列の幅 ÷ 190, .9, 1.5)`）。待機は不透明度0.7
  - 光のにじみ（64pxのやわらかい丸）：半径 人間・待機 24px、ほか 18px（×`sc`）。不透明度 人間 .5、AI .3、失敗 .3、公開済み .22、待機 .18。行に乗せた Issue は不透明度 +.35・半径 +10px
  - 粒（色は誰の番かの色、3px×(0.7〜1.6)）：**人間**は周りを回る粒26個（半径5〜14px、公転 ±0.3〜0.7 rad/s、縦は0.62倍につぶす）。**AI**は回る粒12個＋**尾**12個（光から**左へ**（進む向きの後ろへ）34〜54px流れて消える。名札（右）の文字の上を通らない）。**待機**は大きくゆっくり回る粒16個（半径10〜20px、±0.12〜0.27 rad/s、不透明度0.5）。**失敗**はじっと震える粒16個。**公開済み**は回る粒8個＋右端へ抜けて消える粒12個
  - 誌面の上端より下にある光と粒は不透明度0.3倍（スクロールで誌面の下に入るとき）
- **名札**（HTML の `<button>`。光に追従して `transform: translate(--x, --y)`）：1行目 `#23`（`--mute`、0.92em）＋短い説明（誰の番かの色、500）、2行目 リポジトリ名（`--mute`、0.9em）＋題名（`--bone-2`、0.96em）。文字の大きさ `--nfs`、行の高さ1.25、左右4px・上下2pxの余白、角丸5px。入らない所は「…」で切る。乗せた・フォーカスしたときは題名が `--bone`。名札を押すと、その Issue の説明を下端に固定で出し、押す列のその行へスクロールして最初のボタンにフォーカスする
  - 名札の出し方は3通り：`full`（リポジトリ名つき）／`noRepo`（リポジトリ名なし）／`compact`（公開済み：`#12 公開済み` の1行だけ）。入る幅で `full → noRepo` の順に選び、それでも入らなければ `noRepo` のまま幅で切る
- **配置**（`layoutFlow`）。入力：Issue の並び（人間 → 失敗 → AI → 待機 → 公開済み、同じなら番号の大きい順）、幅、レーンに使える高さ（`--flow-h − 48px`）、名札の文字の大きさ、文字の幅を測る関数。出力：各光の x・y・flip・名札の幅と出し方
  - レーン（行）の最小の高さは `文字の大きさ×2.5+4`（2行ぶん）、上限72px。使えるレーンの数は `高さ ÷ 最小の高さ`
  - 名札が横に使ってよい幅は `span × 列の幅 − 46px`（`span` は 3 → 2 → 1 の順に試す）
  - 列ごとに、その列の光を**縦の真ん中に寄せて**並べる（上から詰めない。中央下が空かないように）。名札の横の範囲（±6pxの余白つき）が同じレーンの物と重なるときは、近い順に別のレーンへずらす
  - 右端に入らない名札：読める幅（`文字の大きさ×22+10`px）が残っていれば、その幅に縮めて切る。残っていなければ `flip`（公開の列は光を右端へ。それ以外の列は、右端に公開済みを積むときだけ光はそのままで名札だけ左へ）
  - **公開済み**（2件以上）は右端に縦に積む：名札は `compact`、間隔 `文字の大きさ×1.25+6`px、ほかの名札が右端の帯（公開済みの名札の最大の幅＋51px）にかかるレーンは飛ばす。全部積めない、またはレーンが高さに入らないときは `span` を縮め、それでも入らなければ公開済みを**1つの光**（`公開済み 8件`、芯は件数ぶんの小さな点が寄り添う、粒は2.2倍）にまとめる。読める幅がある候補のうち、まとめない物 → 名札だけ左へ出した物が5つ以上ある候補より、まとめる候補を先に選ぶ（列が読みにくくなるため）
  - 使ったレーンの塊を、高さの真ん中に置く（レーンの高さは `高さ ÷ 使った数` を上限72pxで）
  - 1024×768 と 1280×800 では公開済みがまとまり、1440×900 以上では右端に積まれる（デモのデータ）
- **説明**（流れの下端、左右 `--gutter`、下10px）：名札に乗せた・フォーカスしたときに1行で出す（0.2秒でフェード）。`todo-app#23`（`--mute`）＋短い説明（誰の番かの色、500）＋理由か説明文（`--bone-2`、12.5px、入らなければ「…」）。理由（順番待ちの理由・公開失敗の理由・止まった理由）があればそれ、無ければ「あなたの番」と同じ長い説明文。止まった理由にこのリポジトリのログのURLがあれば `ログを開く ↗`、公開済みで公開先があれば `開く ↗`（複数なら `App Runner ↗` など種類の名前つき）を続ける。名札を**押した**ときは固定され（リンクを押せる）、流れの外を押すと消える
- **動き**：段階が進んだ光は、前の位置から**ばね**（`k=140, c=20`）で新しい位置へ流れて移る。押す列のボタンを押すと、その光が右へ跳ね（`vu += 160`）、尾の粒が12個噴く。取り直しで入れ替わった光は即座に置く（最初の描画・動きを減らすとき）
- アクセシビリティ：流れの `<section aria-label="パイプラインの流れ">`。名札は `aria-label="todo-app#23 題名。止まっています"`。段階の目盛りは `aria-hidden`（数は上端の帯と凡例で分かる）

## 誌面

`src/components/Desk.tsx`。`position: relative; z-index: 2`、地 `--glass`、`backdrop-filter: blur(22px) saturate(1.2)`、上の端 `mask-image: linear-gradient(to bottom, transparent, #000 34px)`。

### 巨大な数字（左の列）

- 「あなたの番」の件数を、`--giant` の大きさの Bricolage Grotesque 800 で描く。文字は canvas で描き、中を**流れの窓**にする（`engine.ts` の `drawGiant`）：地 `#2A1804`、ゆっくり漂う2つの光（`255,176,64` 不透明度.9 と `255,118,34` .7）、数字の中だけの粒（`幅×高さ÷300` 個、`255,196,96`、7px×(0.6〜1.8)、不透明度 .55 にゆらぎ）。粒は**画面の川と同じ式・同じ向き・同じ速さ**で数字の中を通る。さらに画面の川の粒で数字の上を通っている物は、その場所で明るく（9px、不透明度.8）光る。数字の形で切り抜く（`source-in`）
- 数字が変わるとき：前の数字が上へ抜け（`−高さ×0.9`）、新しい数字が下から上がる（0.46秒、`1−(1−x)³`）。動きを減らすときは即座に変える
- 数字の右に「件」（Bricolage Grotesque 800・30px・`--you`・不透明度0.8、数字の下端にそろえ、間6px）
- その下に `あなたの番`（16px / 500・`--bone`）、その下に `待ちが長い順`（12.5px・`--mute`。0件なら `今はAIの番です`）
- その下にリポジトリごとの件数 `todo-app 5　landing-page 3`（12.5px・`--bone-2`、数は `--bone` 500。間14px）。リポジトリのページでは `todo-app だけ` と `GitHubで開く ↗`（`--mute`、乗せたら `--bone`。デモの架空のリポジトリでは出さない）
- その下に凡例（上22px、縦に7px間隔、12px・`--mute`）：6pxの光る点（`box-shadow: 0 0 8px`）＋ `あなたの番` `AIの番` `待機` `失敗` `公開済み`
- **見張り役の注意**（あるときだけ、凡例の下18px）：`見張り役が {N} 時間動いていません。Actions が止まっていないか確認してください`（12.5px・`--you-soft`、`role="status"`）。ホームはリポジトリ名を前に付ける。無ければ場所ごと出さない
- **取れなかったリポジトリ**（あるときだけ、同じ場所）：`owner/repo：理由`（12.5px・`--fail-soft`）

## 動き（まとめ）

| 場所 | 動き | 長さ |
| --- | --- | --- |
| 川・霧・光の粒・数字の中の粒 | ずっと流れる（上の「映像」「流れ」） | ずっと |
| 段階が進んだ光 | ばね（`k=140, c=20`）で前の位置から流れて移る | 落ち着くまで約1秒 |
| ボタンを押した | ボタンが縮んで塗りつぶし（100ms以内）→ 光が右へ跳ね、粒が噴く → 行が畳まれる（0.36秒）→ 数字が転がる（0.46秒） | — |
| 名札・行に乗せた | 光のにじみが強くなる（10フレームでなめらかに） | 0.2秒 |
| 流れの説明 | フェード | 0.2秒 |
| 取り直しで段階が変わった行 | アンバー（12%）の地から元に戻す | 1.2秒 |
| 新しく入った行・新しい足あとの列 | 上から4px／6px下がりながらフェードイン | 0.2秒／0.5秒 |
| 同期の点 | 速い更新の間は2秒周期に明滅、取り直し中は0.8秒周期に脈打つ | — |
| 進み具合の目盛り | 色が変わるとき0.3秒でなめらかに | 0.3秒 |
| スマホのメニュー | 左から0.18秒で滑り込む | 0.18秒 |
| デモの知らせ | 下から10px上がりながら0.2秒で出る | 0.2秒 |

- 曲線は `--ease`（`cubic-bezier(.2,.8,.2,1)`）。動きは CSS の `transition`・`@keyframes` と canvas で作る。アニメーション用のライブラリは入れない
- **動きを減らす**：端末の `prefers-reduced-motion: reduce`（設定が「端末の設定に従う」のとき）と、設定の「アニメーション：オフ」（`<html data-motion="reduce">`）。「オン」（`data-motion="full"`）は端末の設定にかかわらず動かす。判定は CSS（`globals.css`。すべての `animation`・`transition` を止める）と JS（`src/lib/motion.ts` の `isMotionReduced`。映像の時間を止め、ばね・転がり・畳みを即座にする）で同じ
