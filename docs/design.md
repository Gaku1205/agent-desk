# agent-desk デザイン仕様

画面の見た目のルール。2026年10月25日に、オーナーとデザイン案（ホーム・リポジトリのページ・スマホ・マージ確認）で合意した内容を文章にしたもの。挙動のルールは `docs/spec.md`。

## 方針

- ダークの開発者向け道具。LinearやGitHubの一覧画面に近い、情報が詰まった落ち着いた見た目
- **避けること**（「AIが作った感」の原因）：数字を大きく並べたタイル、角丸の箱を並べただけのカード、ピル型バッジの多用、グラデーション、絵文字、左に色線を引いたカード、大きな塗りつぶしボタンの羅列
- 箱で囲まず、**細い線で区切った一覧**で見せる
- 状態は**色だけで伝えない**。アイコンの形と文言を必ず添える
- 文言は人の言葉で書く（「マージ待ち」ではなく「CI 4/4 通過・マージできます」）

## 文字

- 本文：`IBM Plex Sans JP`（400 / 500 / 600）
- リポジトリ名・Issue番号・PR番号・時刻・件数・キー表示：`JetBrains Mono`（400 / 500）
- どちらも `next/font/google` で読み込む
- 数字は `font-variant-numeric: tabular-nums` で桁をそろえる
- 基本サイズ 15px。見出し 17px / 600（スマホの「あなたの番」は 18px）。「あなたの番」のタイトル 16px。説明文 13.5px。リポジトリ名・番号・時間などの補足 12.5px。パイプラインの列の見出し 12.5px
- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- **改行**：日本語は文節の途中で切らない（「マージで／きます」のような切れ方をさせない）
  - 本文・タイトル・説明文に `word-break: auto-phrase` を付ける（対応していないブラウザでは普通の改行になる）
  - 次の物は折り返さない（`white-space: nowrap`）：ボタンの文字、`agent-desk#22` などの番号、時刻・待ち時間、`CI 4/4` のような数、段階名
  - 1つの行に横に並べる物（番号と待ち時間など）は、幅が足りなければ部品ごと次の行に回す（`flex-wrap: wrap`）。部品の中の文字を2行に割らない

## 形

- 角丸：ボタン 6px（スマホは 8px）、ダイアログ 10px。それ以上丸くしない
- 影は使わない。区切りは線だけ
- タップできる物はスマホで高さ44px以上

## アイコン（状態）

14×14 の SVG。`viewBox="0 0 14 14"`、線の太さ 1.5。色は下の「誰の番か」の色。

| 形 | 使う段階 | 描き方 |
| --- | --- | --- |
| 点線の丸 | 未着手 | `circle r=5.5`、`stroke-dasharray="2.2 2"` |
| 点線の丸に一時停止 | 保留 | 未着手と同じ点線の `circle r=5.5` の中に、縦の2本線 `path d="M5.5 4.8v4.4M8.5 4.8v4.4"`（`stroke-linecap="round"`）。色は人間（`--human`）。形で未着手と区別する |
| 半分塗りの丸 | AI作業中・確認中・公開中 | `circle r=5.5` の輪郭＋右半分を塗る `path d="M7 3.5a3.5 3.5 0 0 1 0 7z"` |
| チェックの丸 | 公開済み | 塗った `circle r=6.25` の上に、背景色のチェック `path d="M4.3 7.2l1.8 1.8 3.6-3.8"` |
| ×の丸 | CI失敗・公開失敗 | 塗った `circle r=6.25`（`--fail`）の上に、背景色の × |
| 二重丸 | 「あなたの番」の行頭 | `circle r=5.5` の輪郭＋中心に `circle r=2` を塗る（`--human`） |

誰の番かの色：人間＝`--human`、AI＝`--ai`、公開済み＝`--done`、失敗＝`--fail`、誰でもない＝`--idle`

## ページの構成（PC）

GitHubと同じく、リポジトリごとにページを分ける。

| ページ | URL | 中身 |
| --- | --- | --- |
| ホーム | `/` | あなたの番（全リポジトリ・2列）＋実行中のパイプライン（全リポジトリ）＋最近の出来事 |
| リポジトリのページ | `/repos/{owner}/{repo}` | あなたの番（そのリポジトリだけ）＋パイプライン |

`WATCHED_REPOS` に無いリポジトリのURLは 404 にする。

### サイドバー（全ページ共通・左）

- 幅240〜260px、右に `--line` の線。上から：
  - `agent-desk`（等幅14px / 500 / `--text-strong`）
  - 「ホーム」（家のアイコン15px）＋右端に全リポジトリの「あなたの番」の件数（等幅12.5px・`--human`）。その右隣に、実行中のパイプラインの件数（等幅12.5px・`--ai`。ホームの「実行中のパイプライン」の見出しの数と同じ青）。2つの数の間は 8px、順番は「あなたの番（オレンジ）→ 実行中（青）」
  - 小見出し「リポジトリ」（12.5px・`--text-mute`）
  - 監視リポジトリを1行ずつ（ファイルのアイコン14px＋リポジトリ名＝`owner/` を省いた名前、等幅13px）。右端にそのリポジトリの「あなたの番」の件数（0件なら出さない）と、その右隣に実行中のパイプラインの件数（ホームの行と同じ書式、0件なら出さない）
- 件数は読み上げで区別できるよう、それぞれに `aria-label`（「あなたの番 2件」「実行中 3件」）を付ける。名前が長いときは名前を「…」で切り、2つの数は縮めず右端に残す
- 1行の高さ36px、角丸6px。今いるページの行は背景 `#17181B`・文字 `--text-strong`・`aria-current="page"`。他の行は文字 `#B4B6BD`
- `<nav aria-label="リポジトリ">` で囲む

### ヘッダー（各ページの上、サイドバーの右）

- 高さ52px、下に `--line`、左右24px
- **スクロールしても固定**：画面の上に `position: sticky`（`top: 0`）で止め、どこまでスクロールしても見え続ける（PC・スマホとも）。背景は `--bg` で塗り、後ろの中身が透けない。重なりの順は、パイプライン表の列見出し・あなたの番の行より手前、サイドバーの重ね表示（スマホ）とダイアログより後ろ
- デモでは、いちばん上の帯（高さ40px）の下に止める（`top: 40px`）
- 左：ホームは「ホーム」（15px / 600）。リポジトリのページは `Gaku1205 / agent-desk`（等幅13px、`Gaku1205` は `--text-sub`、`/` は `#45474D`、リポジトリ名は `--text-strong` / 500）
- 右：リポジトリのページだけ「GitHubで開く ↗」（リポジトリへのリンク、`--text-mute`）。**それ以外は置かない**（同期・更新・ユーザー名・ログアウトはサイドバーの下）

### サイドバーの下（同期・更新・ログアウト）

サイドバーのいちばん下（`margin-top: auto` で下に寄せる）に、上に `--line` の線を引いてまとめる。普段は目立たせない。

- 1行目：`同期 15:42:10`（等幅12.5px・`--text-mute`、更新中は横の点が脈打つ）と、右端に `更新` ボタン（高さ24px・文字12px）
  - 時刻の左の点（6px の丸）：普段は `--text-mute`。5秒ごとに取り直している間は `--ai` でゆっくり明滅。取り直し中の脈打ち（`--ai`）がどれよりも優先
  - 時刻の動き：時刻は最後に取り直した時刻（日本時間 `HH:MM:SS`）のまま動かない。取り直しが終わると、その取り直しの時刻に変わる。書式・色・大きさは変えない
- 2行目：ユーザー名（等幅12.5px・`--text-sub`）と、右端に「ログアウト」（文字だけのボタン、12.5px・`--text-mute`）
- スマホでは≡で開くメニューの中に同じ形で出る。普段の画面には出さない

### 中身の幅

中身は最大幅1320px、左右24px、上28px。セクションどうしの間は36〜40px。

### あなたの番（ホーム・リポジトリのページ共通）

- 見出し「あなたの番」＋件数（等幅・`--human`）、右端に「待ちが長い順」（ホームでは「全リポジトリ・待ちが長い順」）
- **リポジトリのページ**は1件＝1行（1列）
- **ホーム**は2列（幅1100px以上。未満とスマホは1列）。`grid-template-columns: repeat(2, minmax(0, 1fr))`、列の間16px、行の間は今まで通り6px。待ちが長い順に、左→右、上→下へ並べる（奇数なら最後の1件は左列だけ）。行の背景・枠・アニメーションは1列のときと同じ（行の枠の表のとおり）
- 1件の中身（ホーム・リポジトリのページ共通）：
  - `agent-desk#22`（等幅12.5px。リポジトリ名を付ける）、待ち時間（等幅12.5px・右寄せ）
  - 文字の列：タイトル（16px）→ 説明文（13.5px）→ 進み具合のバー（段階名つき）の3段
  - タイトルは**どの幅でも1行**。入らなければ「…」で切り、行に乗せた間は電光掲示板のように流す（動きは「動き」の表の「切れているタイトル」と同じ）。スマホだけは折り返す（下の「スマホ」）
  - 説明文は2行まで。超えたら「…」（スマホは折り返したまま全部出す）
  - バーは文字の列の幅いっぱいに伸ばす（最大幅は付けない）。段階名の出し方は「進み具合のバー」
- **幅ごとの並べ方**：画面の幅ではなく、**1件の行の幅**で決める（CSSのコンテナクエリ。行そのものをコンテナにする）。ホームの2列でも、リポジトリのページの1列でも、同じ境目で切り替わる。行の幅は、例えばリポジトリのページなら 画面幅1440pxで約1140px、1024pxで約730px、900pxで約600px
  - **広い（行の幅1000px以上）**：横1段。左から 二重丸アイコン → `agent-desk#22`（幅150px）→ 文字の列 → 待ち時間 → ボタン（横に並べる、右寄せ）。列の間14px
  - **中くらい（行の幅560〜999px）**：左に二重丸アイコン、右端にボタン（縦に並べる・縦は中央）。その間を2段にし、1段目に `agent-desk#22` と右端に待ち時間、2段目に文字の列。ID専用の幅150pxの列は使わない。列の間14px・段の間6px
  - **狭い（行の幅560px未満）**：中くらいと同じ1段目・2段目の下に、ボタンを回す（文字の列の下、左寄せで横に並べる。上に4px空ける）。ボタンの大きさはPCのまま
  - スマホ（幅900px未満）は行の幅にかかわらず「スマホ」の並べ方
  - どの並べ方でも、ボタン・番号・待ち時間・文字がはみ出したり重なったりしないこと（番号は入らなければ「…」で切る）
- ボタンは枠だけのアンバー（`--human-bg` / `--human-text` / `--human-border`、高さ28px、文字12.5px）。ボタンの幅はどの行でも同じにそろえる（幅92px固定、文字は中央。「マージ…」「PRを作る」「実装を依頼」「確認する」「始める」で幅が変わらないこと）。「マージ」は確認が出るので「マージ…」と表記
- 0件のとき：「今はAIの番です」を `--text-sub` で1行

### 実行中のパイプライン（ホームだけ）

いまAIの番で動いている作業を、全リポジトリぶん、「あなたの番」の下に出す。

- 見出し「実行中のパイプライン」＋件数（等幅・`--ai`）。右端に「全リポジトリ」（12.5px・`--text-mute`）
- 出す物：状態が AIの番（企画中・AI作業中・CI中・レビュー中・修正中・公開中）のIssue。**出さない物**：あなたの番、順番待ち、公開済み、止まった物
- 表は、リポジトリのページの「パイプライン」と同じ（列・棒・行の枠・動き）。違いは次のとおり
  - Issueのセルの2段目は `agent-desk#22`（リポジトリ名つき。リポジトリのページと同じ書き方）
  - 公開済みの開閉・「順番待ち」「並列動作」の件数は出さない
  - 並び順：Issueの番号が大きい順（新しい順）。段階が変わっても行の位置は変えない
  - 行を押すとIssueへ（リポジトリのページと同じ）
- 0件のとき：「いま動いているパイプラインはありません」を `--text-sub` で1行
- スマホは、リポジトリのページと同じ1件＝1ブロックの縦並び

### 最近の出来事（ホームだけ）

- 見出し「最近の出来事」、右端に「直近3日」
- 日ごとに小見出し（「今日」「昨日」、それより前は `10月23日`。12.5px・`#74777F`）をつけ、新しい順に並べる
- 1件＝1行。左から：時刻 `16:57`（等幅12.5px・`--text-mute`・幅44px）→ 22×22・角丸6pxの四角に12pxのアイコン → 2段（出来事の文＝`--text`、下に `agent-desk#8・PR #18`＝等幅12.5px・`--text-mute`）
- 四角の背景と、アイコンの色：

| 種類 | 背景 | アイコンの色 |
| --- | --- | --- |
| 人間の番になった | `#241B0E` | `--human` |
| AIが動いた | `#101B2D` | `--ai` |
| 公開された | `#0F2219` | `--done` |
| 失敗した | `#2A1213` | `--fail` |
| あなたがした操作 | `#17181B` | `--text-sub` |

- 出来事の種類・文・アイコンは下の「出来事の一覧」のとおり
- 0件のとき：「直近3日の出来事はありません」を `--text-sub` で1行

### パイプライン（リポジトリのページだけ）

Issueを行、パイプラインの5段階を列にした表。Issueの行は上下に動かず、作業が進むとバーが右に伸びる。

- 列の見出しの行は、上のヘッダーの下に張り付く（`position: sticky`、背景 `--bg`。表をスクロールしても読める。ホームの「実行中のパイプライン」の表も同じ）
- 見出し「パイプライン」＋「直近14日・新しい順」（12.5px・`--text-mute`）。その右に「順番待ち 3件」「並列動作：1件」（同じ大きさ。件数が0なら出さない）
- 見出しの行には、公開済みの表示・非表示の切り替えを置かない（表の一番下に置く。下の「公開済みの行」）
- 列：`Issue`（幅は表の幅の28%。ただし200〜320px）＋ `清書` `実装` `PR` `CI` `レビュー` `修正` `マージ` `公開`（残りを8等分）。CSS grid で `clamp(200px, 28cqw, 320px) repeat(8, minmax(0, 1fr))`（`cqw` は表を包む物の幅。下のコンテナクエリと同じ物）
- **表の幅が720px未満のとき**は、スマホと同じ「1件＝1ブロック」の縦並びにする（「スマホ」の「パイプライン」と同じ。列の見出しは出さない）。画面の幅ではなく**表の幅**で決める（CSSのコンテナクエリ。表を包む物をコンテナにする）。段階の列が約52px（いちばん長い見出し「レビュー」が隣と重ならない幅）を切る前に切り替えるため。画面幅900px（サイドバーあり）では表の幅は約600pxなのでブロックになり、1024px以上は表になる
- 列の見出し行：高さ40px、12.5px・`#74777F`、段階名は中央寄せ。上下に `--line`
- Issueの行：高さ52px以上、上下の余白8px・左右の余白12px（枠の内側に中身を置くため）、下に `--line-soft`（枠のある行は枠が覆うので線を見せない）。行全体がIssueへのリンク。列見出しの行も左右12pxにして、列の位置を行と揃える
  - Issueのセル：タイトル（`--text`、1行で入らなければ「…」で切る）、下に `agent-desk#22`（等幅12.5px・`--text-mute`）
  - 段階のセル（8つ）：高さ4px・角丸2pxの棒、その下に説明（12.5px）。説明は**今の段階のセルにだけ**出す（公開済みは「公開」のセルに出す）。説明の色は誰の番かの色（人間 `#D39A43`、AI `#7FA9EC`、公開済み `--done`、失敗 `--fail`）。1行で入らなければ「…」で切る
  - 棒の色は「進み具合のバー」のルール
- 公開済みの行は全体を不透明度0.62にして、終わった物として目立たなくする
- 並び順：まだ終わっていない行を上に、Issueの番号が大きい順（新しい順）。段階が変わっても行の位置は変えない。公開済みの行は、その下にまとめる
- **公開済みの行**：最初は出さない。表の一番下に、文字と三角の開閉（「理由を見る」と同じ見た目）を中央寄せで置く
  - 1件も出していないとき：`公開済みを表示（19件） ▾`
  - 押すたびに、新しい順に5件ずつ足して出す。まだ残っていれば `さらに5件表示（残り14件） ▾`
  - 1件以上出しているときは、その横に `公開済みを隠す ▴`（押すと全部しまう）
  - 公開済みが0件なら、この行ごと出さない
- `role="table"` / `role="row"` / `role="columnheader"` / `role="cell"` を付ける
- 0件のとき：「直近14日のIssueはありません」を `--text-sub` で1行

## 幅を変えたときの決まり（PC 900〜1920px・スマホ390px）

どの幅でも、はみ出し・重なり・文字の切れが出ないようにする。画面ごとの決まりは各セクションにある。ここは、画面をまたいで守る決まり。

- 横並びの行の中で、長くなる文字の箱（リポジトリ名・タイトル・ユーザー名）は `min-width: 0` を付け、入らなければ「…」で1行に切る。固定の幅を持つ部品（アイコン・時刻・件数・ボタン）は縮ませない
- ヘッダーのリポジトリ名（`Gaku1205 / agent-desk`）は、長くて入らなければ「…」で切る（右の「GitHubで開く ↗」は縮ませない）。スマホのページ名も同じ
- 最近の出来事の文は、英数字だけの長い語（URLなど）が来ても箱の外に出さず、途中で折り返す。2段目の `agent-desk#8・PR #18` は折り返さず、入らなければ「…」で切る

## 行の枠（パイプライン表）

パイプライン表の行（スマホではブロック）には、今の状態の色で枠を付ける。バーと同じ色で、どの行が誰の番か遠くからでも分かるようにする。枠の形と、枠と中身の余白は全部の状態で同じにし、枠のある行と無い行で中身の位置がずれないようにする。

| 状態 | 枠の色 | 動き |
| --- | --- | --- |
| AIの番（清書中・実装中・CI中・レビュー中・修正中・公開中） | `--ai`（青） | 光が枠を回る（1周2.4秒） |
| あなたの番（未着手・保留・PR作成待ち・`ai:hold` のマージ待ち・止まった） | `--human`（アンバー） | 不透明度 0.45 ↔ 1.0 で明滅（1周1.6秒。待たせている物なので、順番待ちより少し速く目立たせる） |
| 順番待ち・やり直し待ち | `--queue`（紫） | 不透明度 0.35 ↔ 0.8 でゆっくり明滅（1周2.4秒）。やり直し待ちは人間が何もしなくてよいので、「止まった」（アンバーの明滅）より控えめな、順番待ちと同じ枠にする |
| 失敗（CI失敗・公開失敗） | `--fail`（赤） | 動かない（点灯） |
| 公開済み | 枠なし | なし（終わった物は静かに） |

- `prefers-reduced-motion: reduce` のときは、回る・明滅をやめて、枠を点灯だけにする
- 枠は行の外形と同じ位置（`inset: 0`）に収め、太さ2pxの枠は行の外へはみ出さない。中身は枠の内側（左右12px・上下はPC 8px／スマホ 10px）に置き、枠と中身は重ならない。回る枠・明滅する枠・赤い枠は同じ位置・同じ太さ
- スマホ／狭い表（幅720px未満）のブロックの寸法：上下の余白10px・左右12px、中の段の間6px
- 行と行の間は6px空ける（PCの表もスマホのブロックも）。隣り合う行の枠が重ならないようにし、どの枠も4辺が全部見えるようにする。枠の無い行（公開済み）も同じ間隔で並べ、行の位置がずれないようにする
- 表の先頭の行は、列見出しの行との間にも6px空け、枠の上辺が見出しに隠れないようにする。列見出しが出ていないスマホのブロックでは空けない
- 「理由を見る」などの開閉は、箱のボタンにせず**文字＋小さい三角**で出す：`理由を見る ▾`（12.5px・`--text-sub`、三角は10px）。枠・背景は付けない。開いているときは三角を上向き（180度回す、0.15秒）。乗せたときは文字を `--text`。スマホでも見た目は同じで、押せる範囲だけ高さ44px に広げる（見た目の高さは変えない）

  - `修正`：AIに直させていないPR（spec.md の「修正した」が偽）で、`at` が6以上のとき

**色の付け方**：今の位置までの棒を、**全部同じ色（誰の番かの色）で埋め**、左（古い段階）ほど暗く、今の段階をいちばん明るくする。フェーズが変わって誰の番かが変わると、埋まっている棒全体の色が変わる。

- 1段階＝1本の細い棒（高さ4px、角丸2px、棒どうしの間3px）
- 「あなたの番」の行（PC）：説明文の下（上に6px空ける）、文字の列の幅いっぱい（最大幅は付けない）。各棒の下に段階名（11.5px、左寄せ）。今の段階の名前だけ `#C9CBD1`、他は `--text-mute`
  - 段階名を8つ全部出すのは、**バーの幅が420px以上**のとき（1本あたり約50pxあれば、いちばん長い「レビュー」も隣と重ならない）。420px未満では、スマホと同じく**今の段階の名前だけ**を出す（他の段階名は場所だけ取って見せない。バーの下の高さは変わらない）。バーの幅で決める（CSSのコンテナクエリ。バーを包む物をコンテナにする）
- 「あなたの番」の行（スマホ）：幅いっぱい。段階名は**今の段階の名前だけ**を、その棒の下に出す（8つ並べると潰れるため）
- パイプライン表：表の各段階のセルに1本ずつ（段階名は列の見出しにあるので付けない）
- スクリーンリーダー向けに `role="img"` と `aria-label="進み具合 {at}/8・{今の段階の名前}"` を付ける（公開済みは「進み具合 8/8・公開済み」。パイプライン表では行に付ける）
- 段階から棒の色・不透明度・枠線だけかを決める処理は `src/lib/` の関数にまとめてテストする

- 下：「やめる `Esc`」（枠だけ）と「マージする `⏎`」（`--human` で塗る。塗りつぶしのボタンはここだけ）
- `Esc` で閉じる、`Enter` でマージ。開いたときのフォーカスは「やめる」

## 動き（控えめに、意味のある所だけ）

| 場所 | 動き | 長さ |
| --- | --- | --- |
| AI作業中のアイコン | 半分塗りの部分がゆっくり回る | 1周2.4秒、ずっと |
| 自動更新で段階が変わった行（あなたの番・パイプライン） | 背景を誰の番かの色（透明度12%）から元に戻す | 1.2秒で消える |
| 切れているタイトル（パイプライン表・あなたの番・実行中のパイプライン。PCだけ） | 行に乗せた間（キーボードならフォーカス中）だけ、電光掲示板のように右から左へ流す。0.3秒待ってから、秒速60pxで、切れている分だけ流す。収まっているタイトルは動かさない。「動き」の設定が「控えめ」のときは動かさない | 切れている分÷60秒 |
| 進み具合の棒 | 色が変わるとき 0.3秒でなめらかに変える | 0.3秒 |
| パイプライン表の行の枠 | 下の「行の枠」のとおり、状態ごとの色と動き | 下の表 |
| あなたの番に新しく入った行 | 上から4px下がりながらフェードイン | 0.2秒 |
| 更新中の同期表示 | 時刻の横の点が脈打つ | 更新が終わるまで |
| 速い更新（5秒ごと）の同期表示 | 時刻の横の点が不透明度 1 ↔ 0.35 でゆっくり明滅 | 1周2秒、5秒ごとの間ずっと |
| マージ確認ダイアログ | 開くとき、フェード＋98%→100%の拡大 | 0.12秒 |

- `prefers-reduced-motion: reduce` のときは、回転・脈打ち・移動・拡大を止める（色の変化だけは残してよい）
- スマホのメニューの出し入れ：左から0.15秒で滑り込む（`prefers-reduced-motion` のときは滑らせない）
- 動きは CSS の `transition` と `@keyframes` で作る。アニメーション用のライブラリは入れない
