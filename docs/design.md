# agent-desk デザイン仕様

画面の見た目のルール。2026年11月15日に、それまでの「流れ × 誌面」（光の粒・極太の数字・画面全体の川）をやめ、**1カラムの会話形式**に作り直した（Issue #281。画面案は作らず、この文章で決めた）。挙動のルールは `docs/spec.md`。

## 方針

- 体験の核：**開くと、画面の真ん中に「今あなたが答えること」が1つだけある。** 質問・説明とボタン（と答えの欄）だけが最初の1画面に見え、片づけると次の1件に替わる。その下に、AIたちの進み具合が、会話のメッセージのように縦に流れる
- スマホ（幅899px以下）の画面は**読みやすい幅の1本の列**。左右に別の列を置かない。PC（幅900px以上）のホームとリポジトリのページだけは**3ペイン**（左：リポジトリの一覧／中央：あなたの番・いまの様子・下にIssueを追加する入力欄／右：進捗図の列。2026年11月15日、Issue #286 のオーナーの指示で変え、2026年11月16日、Issue #300 で進捗図を右の列の縦の図に移した。下の「PCの3ペイン」）。中央の「あなたの番」と「いまの様子」は、今までどおりの読みやすい幅の1本の列。設定・Issueを書く・ログイン・見つからないページは、PC でも1本の列
- **余白と文字が中心**。色は最小（地・文字・薄い文字・強調の1色（インディゴ）と失敗の赤、成功の緑）。大きさ・太さ・行間・余白の差で、何が主役かを見せる。地味で無難な画面にしない（行間を詰めた小さい字の羅列、どこも同じ大きさの字にしない）
- 雰囲気の参考は Claude アプリの会話画面（コピーはしない）：無彩色の地（白と黒の2テーマ）に、読みやすい文字、広い行間
- **軽く**：光の粒・極太の数字・キャンバスの描画・すりガラス（`backdrop-filter`）・凝った動きは使わない。動きは切り替わりの短いフェードだけ。**例外は「いまの様子」のランプの緑だけ**：静かに脈打つ（明るさだけがゆっくり変わる。2026年11月16日、Issue #295 のオーナーの指示。下の「ランプ」）
- **避けること**：数字を大きく並べたタイル、同じ角丸・同じ影のカードの並び、ピル型バッジの多用、飾りのグラデーション、絵文字、太い枠・硬い黒線、見出し上の字間を空けた英大文字、光る点・にじみ（**「いまの様子」のランプの、脈打つ緑の丸だけは例外**。光（影・にじみ）は付けない）、標準のフォーム部品をそのまま枠に並べた物、塗りつぶしのインディゴを「オン」などの状態に流用すること
- 状態は色だけで伝えない。「あなたの番」は種類の札と説明文、会話は話し手と文を持つ
- **強い色は、ほんとうに急ぐ所だけ**：インディゴの塗り（ボタン）は「止まった」の1件（とログインの入口）だけ、赤の塗りは「公開失敗」の1件だけ。ほかの1件の主役のボタンは文字色（`--bone`）の塗り
- **キーボード**：Tab で回る数を少なく保つ。最初に届くのは「あなたの番」の1件のボタン
- リンク：アプリの中のページ（`/` で始まるURL）は同じタブで開く。外のサイト（`https://`）だけ新しいタブで開く
- 文言は人の言葉で短く。会話の文は「いま〇〇が△△しています」のように、声に出して読める日本語にする。日本語の文は「、」「。」で分けた塊ごとに折る（文節の途中で切らない）

- 白と黒どちらでも、文字と地の比は 4.5:1 以上（`--bone`・`--bone-2`・`--mute`・各 `-soft`・`--accent`・`--ok`・`--wait`。不透明度を下げて薄くした文字は作らない）
- **アンバーはやめた**。以前アンバー（`--you`）で塗っていた所は、インディゴ（`--accent`）にする。`--you`・`--you-soft`・`--ai`・`--q`・`--done`・`--done-soft` は無くした
- **色だけで意味を伝えない**。インディゴ＝「あなたの番」の見出し・種類の札の文言・ボタンの文字、緑＝チェックの形、赤＝×の形・`公開に失敗` などの文言を、必ず併せて出す
- **選び方**（挙動は `docs/spec.md` の「テーマ」）：`<html data-theme="light">`（白）・`"dark"`（黒）。付いていないとき（OSに合わせる）は `prefers-color-scheme` で決める。`color-scheme` も合わせる（標準のスクロールバーなどが追従する）
- 色の直書きが許されるのは次だけ：`globals.css` の変数の値、`mask-image` の `#000`（色ではなく透け具合）、`layout.tsx` の `Viewport.themeColor`（ブラウザの外枠の色なのでCSS変数が使えない。白 `#FAFAFA`・黒 `#121212` を `prefers-color-scheme` で出し分ける。設定で手で選んだときは追従しない）、`src/lib/demo/` のサンプルのデータの色の見本（画面の色ではなく、見た目の方向という「中身」）
- 仮に決めた所（画面案なし）：白・黒の各値（インディゴは `#4F46E5` / `#818CF8`、地は `#FAFAFA` / `#121212` を基準に）、緑、縁・下地の不透明度、後ろの幕の濃さ

## 文字

- 和文：`IBM Plex Sans JP`（400 / 500 / 700）。欧文・数字：`Geist`（可変）。ワードマーク：`Bricolage Grotesque` 800（`font-variation-settings: "opsz" 96`）
- 3つとも `next/font/google` で読む（`src/app/layout.tsx`。変数は `--font-jp`・`--font-latin`・`--font-disp`）。本文の指定は `--jp`（Geist → IBM Plex Sans JP の順）
- 等幅フォントは使わない。番号・時刻・件数は Geist の `tabular-nums`（`.num`）で桁をそろえる
- 大きさの段（PC／スマホ）：
  - 「あなたの番」の題名 30px／21px（700、行の高さ1.4、字間 −0.01em、`text-wrap: balance`）
  - 「あなたの番」の説明文 17.5px／15.5px（行の高さ1.8）
  - 会話の文 16px／15.5px（行の高さ1.75）
  - 小見出し・札・ボタン 13〜14.5px、補足 12.5〜13px
- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 文字の色は、地に対して 4.5:1 以上になる物だけを使う（`--bone`・`--bone-2`・`--mute`・各 `-soft`。不透明度を下げて薄くした文字は作らない）
- 本文は `font-feature-settings: "palt"`（かなを詰める）
- **改行**：`word-break: auto-phrase`（文節の途中で切らない）。説明文は「、」「。」のあとで `span.ph` に分け、塊ごとに折る（`src/lib/turnKind.ts` の `splitPhrases`）。折り返さない物（`white-space: nowrap`）：番号、時刻・待ち時間、ボタンの文字、足あとの1つ1つ

## アイコン

画面のラベル（ボタン・リンク・メニューの項目・一覧の項目・設定などの見出し）の左に、線だけのアイコンを置く。形は `src/components/icons.tsx` に、Lucide に近い線画を SVG で書く（パッケージは入れない）。進捗図の工程のアイコンも状態の印も、同じ描き方。

- **描き方**：`viewBox="0 0 24 24"`、`fill="none"`、線の太さ1.5、`stroke-linecap` と `stroke-linejoin` は `round`。塗りつぶしは使わない
- **大きさ**：ラベルのアイコンは16px（見出し `h2` も16px）。工程のアイコンは17px。小さな状態の印は14px。どれも16〜18pxの外へは出さない（状態の印だけ14px）
- **色**：`stroke="currentColor"`、つまり左の文字と同じ色。**選択中**（今いるリポジトリの札・今いるページのリンク）と**進行中**（回る印・今の位置の工程）のアイコンだけ `--accent`。押せない物は文字と一緒に薄くなる
- **並べ方**：アイコン → 文字の順、間7px（見出しは間8px）、縮めない（`flex-shrink: 0`）、文字と縦の真ん中でそろえる。ボタンやリンクの高さ・左右の余白は変えない（アイコンの分だけ幅が増える）
- **飾り**：すべて `aria-hidden="true"`。ボタンやリンクの読み上げの名前（文言）は変えない
- **付けない所**：本文の文章、入力欄の見本の文字、エラー文、数字の札、ランプや点のように**それ自体が状態を示す印**を持つ物（同期の点、テーマ・アニメーションの選択、通知のオン・オフ、`全部おまかせ`、`新しいサービスを自動で追加`）、選択欄の `▼`、小さな名札（`ほか` など）
- **形の割り当て**：全部＝グリッド、リポジトリ＝フォルダ、Issueを書く＝ペン付きの四角、設定＝歯車、ログアウト＝出る矢印、ログイン＝入る矢印、GitHubで見る＝枝分かれ、デモの再生＝三角、保存＝フロッピー、追加＝＋、外す・閉じる＝×、通知＝ベル、テーマ＝太陽、アニメーション＝波形、キーボード操作＝キーボード、メモ＝書類、選択肢（質問・相談）＝丸（選んだら丸にチェック）、`全部ちがう`＝戻す矢印、`作る`＝三角、`直す`＝レンチ

## 回数制限の知らせ

## 動き（まとめ）

| 場所 | 動き | 長さ |
| --- | --- | --- |
| 「あなたの番」の1件が替わった | 新しい1件が不透明度0から1へ（動かさない） | 0.18秒 |
| 新しく入った会話のメッセージ・開いた公開済み | 不透明度0から1へ | 0.18秒 |
| ボタンを押した | 色が即座に変わる（100ms以内） | — |
| 同期の点 | 速い更新の間は2秒周期に明滅、取り直し中は0.8秒周期に脈打つ | — |
| 押した札の点・押した `設定` の歯車 | 次の画面が出るまで0.8秒周期に脈打つ（動きを減らすときは色が `--bone` に変わるだけ） | 画面が出るまで |
| スマホのメニュー | 左から0.18秒で滑り込む | 0.18秒 |
| デモの知らせ | 下から10px上がりながら0.2秒で出る | 0.2秒 |
| 「いまの様子」のランプ（動作中の緑だけ） | 明るさ（不透明度 1 ↔ 0.35）がゆっくり変わる。ずっと。赤・紫の数字は動かない | 2.4秒周期 |
| 設定のランプ | 押している間は縮み（`scale(.7)`）、離すと戻る。塗りは0.12秒で入れ替わる | 0.22秒 |

- 曲線は `--ease`（`cubic-bezier(.2,.8,.2,1)`）。動きは CSS の `transition`・`@keyframes` だけで作る（キャンバスは使わない）。アニメーション用のライブラリは入れない
- **動きを減らす**：端末の `prefers-reduced-motion: reduce`（設定が「端末の設定に従う」のとき）と、設定の「アニメーション：オフ」（`<html data-motion="reduce">`）。「オン」（`data-motion="full"`）は端末の設定にかかわらず動かす。判定は CSS（`globals.css`。すべての `animation`・`transition` を止める）と JS（`src/lib/motion.ts` の `isMotionReduced`）で同じ
