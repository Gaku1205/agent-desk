# agent-desk デザイン仕様

画面の見た目のルール。2026年10月29日に、構図の違う下書き3案を比べて決めた方向「流れ × 誌面」（下書き：`docs/mockups/flow-editorial.html`。見本であり、本番のコードではない）を文章にしたもの。挙動のルールは `docs/spec.md`。

## 方針

- 体験の核：**夜の地を左から右へ流れる何本かの細い光の筋（レーン）の上を、自分の Issue の光が段階ごとに進んでいて、その同じ流れが左の極太の数字の中を通り抜け、通った粒は琥珀色に灯ったまま流れていく。** ボタンを押すと、その Issue の光が自分の筋の上を次の段階の列まで飛んで行き、行が畳まれ、数字が転がって減る。静止画でも、筋の上の光の尾と、筋を走るきらめきで、流れの向き（左から右）が分かる
- 画面は上下の2つ。**上は「流れ」**（細い帯。Issue が光の粒になって、段階の列を左から右へ進む映像）、**下は「誌面」**（巨大な数字 ＋ 押す列 ＋ 出来事）。**主役は押す列**：PC の最初の1画面に、押す列が3件以上入る。パネルで区切った定番の画面にしない
- 流れに常に名札を出すのは、**人間の番と失敗だけ**。ほかの Issue は筋の上の1つの光と、段階ごとの件数だけにし、名札は乗せた・フォーカスした・押したときだけ出す（名札の壁にしない）。名前の無い光を粒の群れにしない（星空に見えて、流れに見えなくなる）。公開済みは右端の小さな1つの塊にまとめる（終わった物がいちばん目立たないように）
- **名札は動かさない**：Issue のレーンと筋の上の位置は、その Issue が同じ段階の列にいる間は変えない。押した物・段階が変わった物だけが動き、動いている間はその名札を隠し、着いてから出す
- 映像は画面の端まで届かせる。板で画面を分けない。誌面の地は、上の端を34pxのグラデーションで消した半透明の夜（硬い境目を作らない）。すりガラス（`backdrop-filter`）は上端の帯と、乗せたときの名札だけに使う（広い面にかけると重い）
- 生きている映像は**1系統だけ**：流れ（画面全体の川と、Issue の光の粒、巨大な数字の中の粒）。どれも同じ式で同じ向き・同じ速さに動く。霧・数字の中の光は止めておく（毎日見て疲れない量にし、軽くする）
- 名札・補足は端に置き、短く。大きさの差でアクセントを作る（巨大な数字と小さな「件」）
- **避けること**：数字を大きく並べたタイル、同じ角丸・同じ影のカードの並び、ピル型バッジの多用、飾りのグラデーション、絵文字、太い枠・硬い黒線・全面の縦線、見出し上の字間を空けた英大文字、左上の小さいタイトル＋1行の説明文、標準のフォーム部品をそのまま枠に並べた物、塗りつぶしのアンバー（あなたの番の色）を「オン」などの状態に流用すること
- 状態は色だけで伝えない。流れの名札は短い説明の文字を持ち、押す列は「種類」の札と説明文を持つ。色の凡例は流れの下端の右に置く
- **強い色は、ほんとうに急ぐ所だけ**：押す列の強い色の塗り（アンバー・失敗の赤のボタン）は「止まった」と「公開失敗」の行だけ。**強い色の行は、押す列の一番上に集める**（色と並び順が食い違わないように）。ほかの行の種類の札・ボタン・進み具合の目盛りは静かな色（`--bone-2`・`--bone`）に落とす。アンバーを全部の行にまき散らすと、止まった物が埋もれる。**流れの名札も同じ**：誰の番かの色の太字は、急ぐ物（止まった・公開失敗。`FlowNode` の `urgent`）だけ。ほかの人間の番・CI失敗などの名札の短い説明は `--bone-2`
- **キーボード**：Tab で回る数を少なく保つ。流れの名札は1つの停止点にまとめ、中は矢印キーで動く。見えない物（不透明度0・隠した物）にはフォーカスが止まらない
- リンク：アプリの中のページ（`/` で始まるURL）は同じタブで開く。外のサイト（`https://`）だけ新しいタブで開く
- 文言は人の言葉で短く。名札は1語（英語1語も可）。日本語の文は「、」「。」で分けた塊ごとに折る（文節の途中で切らない）

| `--you` | `#F5A73A` | あなたの番（アンバー。巨大な数字の光もこの系統） |
| `--ai` | `#5B8DFF` | AIの番（信号の青） |

## 文字

- 和文：`IBM Plex Sans JP`（400 / 500 / 700）。欧文・数字：`Geist`（可変）。見出し・巨大な数字・ワードマーク：`Bricolage Grotesque` 800（`font-variation-settings: "opsz" 96`）
- 3つとも `next/font/google` で読む（`src/app/layout.tsx`。変数は `--font-jp`・`--font-latin`・`--font-disp`）。本文の指定は `--jp`（Geist → IBM Plex Sans JP の順）、見出しは `--disp`
- 等幅フォントは使わない。番号・時刻・件数は Geist の `tabular-nums`（`.num`）で桁をそろえる
- 字間：ワードマーク `-0.045em`、巨大な数字 `-0.06em`、「件」 `-0.04em`、題名 `-0.005em`
- 大きさの段：巨大な数字 `--giant`（`clamp(200px, min(19vw + 10svh − 90px, 46svh), 600px)`。画面の高さでも伸びる：1024×768 で200px、1440×900 で274px、1920×1080 で383px、2560×1080 で497px、2560×1440 で540px。スマホ 128px）／リポジトリごとの内訳の数 22〜56px（下の「巨大な数字」）／「件」30px（スマホ 26px）／題名 16px（スマホ 15.5px）／本文 13.5px・13px／小 12.5px・12px／流れの名札 `--nfs`（`clamp(11.5px, .23vw + 9.2px, 15px)`。幅で変える）／段階の目盛り 12px、その件数 11.5px
- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 文字の色は、地に対して 4.5:1 以上になる物だけを使う（`--bone`・`--bone-2`・`--mute`・各 `-soft`。不透明度を下げて薄くした文字は作らない）
- 本文は `font-feature-settings: "palt"`（かなを詰める）
- **改行**：`word-break: auto-phrase`（文節の途中で切らない）。説明文は「、」「。」のあとで `span.ph` に分け、塊ごとに折る（`src/lib/turnKind.ts` の `splitPhrases`）。折り返さない物（`white-space: nowrap`）：名札、番号、時刻・待ち時間、ボタンの文字、段階名、出来事の足あとの1つ1つ

## 映像（画面全体）

`src/components/flow/engine.ts`。画面いっぱいの1枚の `position: fixed` の canvas（川。`pointer-events: none`）と、`body` の背景の霧。

- **霧**（いちばん下。`body` の背景の画像。不透明度0.9を色に掛けて描く）：1/4 の解像度の canvas に1回だけ描き、`background-image`（`background-size: 100% 100%`、`background-attachment: fixed`）にして引き伸ばす。画面いっぱいの canvas の層を重ねない（GPU の無い環境で、毎フレームの重ね合わせが重い）。5つの大きな丸い光（位置は画面の割合、色・不透明度：`(.14,.42) 人間 .2`、`(.55,.3) AI .18`、`(.9,.4) 公開済み .13`、`(.36,.7) AI .12`、`(.72,.74) 待機 .1`、半径は画面の長い辺の36%）。**動かさない**：画面の大きさが変わったときだけ描き直す（生きている映像は流れの1系統だけ）
- **川**（上の層。`z-index: 3`。誌面（`z-index: 2`）より上に描く）：粒の数は PC `min(900, 幅×高さ÷1800)`、スマホ 220。色 `150,165,205`、大きさ 4px×(0.5〜1.7)、不透明度 0.15 にゆらぎ（`.55+.45·sin(t·1.1+位相)`）。右へ 24px/秒 ＋ ノイズの curl（発散しない流れ。振幅 12）で揺れながら流れ、右端を出たら左端から入り直す。誌面の上端（＋30px）より下では不透明度を 0.3 倍にする
- **灯った粒**：川の粒が巨大な数字の形の中を通ると「灯り」（熱 1）、琥珀色 `255,196,96` で光る。数字を出たあとも同じ流れのまま右へ進み、熱は `e^(−0.7·秒)` で冷める（約3秒で消える）。灯った粒の不透明度は `.15·ゆらぎ + .55·熱`（誌面の中でも暗くしない）、大きさは `4px×(1+.8·熱)`。数字の形の判定は、数字を描き直すたびに作る1倍の大きさの型（不透明度0.5以上の画素）で行う
- **灯った粒は、文字やボタンの上に描かない**：灯って見えるのは「灯りの区域」の中だけ。区域は、横が数字の左60pxから**押す列の左端の10px手前**まで（スマホは「件」の右端の6px先まで。右隣の `あなたの番` の文字にかからない）、縦が数字の上40px〜下16px。区域の端の30pxで灯りを薄くし、区域の外では熱が残っていても冷たい川の粒として描く（スクロールで数字が動いても、押す列の文字・ボタンの上を金の粒が流れない）。数字の高さの帯を流れる粒（下の「数字を通る流れ」）も、この区域の右端で消える
- **描くのを止めるとき**：タブが見えていない（`document.hidden`）とき、流れ（`<section aria-label="パイプラインの流れ">`）が画面の外（上端の帯52pxの下に1pxも見えていない。`IntersectionObserver`）にあるときは、`requestAnimationFrame` を止め、映像の時間も進めない（川は止まった1枚になる）。また見えたら、止めた所から続ける。止めている間でも、巨大な数字の転がり（押したとき）だけは描く（数字は sticky で見えている）。設定などの流れの無いページは、タブが見えている間は描く
- **数字を通る流れ**：数字の高さの帯にだけ、川の粒を足す（数（数字の幅＋150）×高さ÷900 個）。数字の左60pxから入り、川と同じ式で右へ流れ、数字の中で灯り（不透明度 `.08·ゆらぎ + .7·熱`、大きさ `4px×(1+.6·熱)`）、数字の右90pxまで（灯りの区域の右端の方が手前なら、そこまで）灯ったまま流れて消える（冷たい粒は `150,165,205` の不透明度 `.22·ゆらぎ`）。帯の両端30〜40pxで薄くする。最初の描画から、数字を出た粒は冷めかけの状態にしておく（開いた瞬間から流れが見える）。巨大な数字が sticky で動いても、帯は数字に付いて動く
- 粒の初期位置は種から決まる乱数（`src/lib/flow/random.ts`）で、見た目のテストで毎回同じになる
- `devicePixelRatio` は 1.5 まで（川）、2 まで（巨大な数字）
- **動きを減らす**（下の「動き」）：時間を進めず、川・粒・ばねを止める。画面の大きさ・データ・スクロールが変わったときだけ描き直す

## 流れ（PC）

`src/components/flow/FlowStage.tsx`（要素）と `src/lib/flow/layout.ts`（配置の純粋関数）。

- 場所：上端の帯の下、高さ `--flow-h`（200〜420px）、左右の余白 `--gutter`。`overflow: hidden`。中は上から、段階の目盛り（30px）・光の区域（`--flow-h − 56px`）・下端の行（26px：説明と凡例）
- **段階の目盛り**（上端、`position: absolute`、上4px）：8列の grid（`repeat(8, minmax(0,1fr))`）に `清書 実装 PR CI レビュー 修正 マージ 公開`（12px・`--bone-2`、列の左端から20px）と、その段階にある Issue の数（12px / 500・`--bone`、名前との間6px。0なら出さない）。名前の下に1px×7pxの短い目盛り線（`--mute`・不透明度0.6）。名札を出さない光は、この件数で数が分かる
